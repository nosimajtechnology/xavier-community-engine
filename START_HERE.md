# Start Here

## Five-minute workflow

1. Invoke `$xavier-community-engine` and describe the result in ordinary language.
2. Attach any project-specific references. Xavier's bundled canonical sheet remains the identity authority.
3. The engine selects a mode, sources the relevant visual grounding, and creates a compact Scene Lock.
4. For multi-shot work, approve the Genesis Frame before the engine expands it into connected shots.
5. Approve the storyboard before requesting a Seedance, Kling, or other provider-specific prompt.

The Genesis Frame prevents a strong idea from being expanded around the wrong anatomy, camera, geography, or rendering target. Approval locks what is already correct; later repair should change only the failed layer.

## Copyable starters

```text
Use $xavier-community-engine. Xavier tries to help a grocery-store customer carry emotional baggage, and the baggage becomes physically heavier. Make a 12-second lost-PS2 scene.
```

```text
Use $xavier-community-engine to make one captionless meme still of Xavier confronting the Sunday-night feeling. Keep it sincere and visually readable.
```

```text
Use $xavier-community-engine in REPAIR mode. Keep the approved framing and environment exactly the same; restore Xavier's canonical snake-arm side, eye colors, and backward-hinged legs.
```

## Reference use

Do not redraw or improve the bundled character sheet. Attach it as the highest identity and base-construction reference whenever the image workflow supports references. New environment references may control camera, lighting, fog, props, and world density, but never Xavier's anatomy or surface construction.
