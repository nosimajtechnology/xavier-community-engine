# Start Here

## Five-minute workflow

1. Start with `@Xavier Community Engine` and describe what Xavier is doing.
2. The Engine creates the first image.
3. Reply `Approved.` when Xavier and the setting look right.
4. For a video, the Engine builds the connected shots and waits for your approval.
5. It then prepares the final prompt for your video tool.

Approval locks what is already working. If something is wrong, name only that detail so the Engine preserves the rest.

## Copyable starters

```text
@Xavier Community Engine Xavier sees a man arguing with his reflection and tries to separate them. Make it a short PS2-style scene.
```

```text
@Xavier Community Engine make one captionless image of Xavier adopting an abandoned pothole.
```

```text
@Xavier Community Engine keep everything else the same and move Xavier's snake arm back to the correct side.
```

## Reference use

The bundled character sheet keeps Xavier recognizable. Settings and poses can change, but the Engine should preserve his defining anatomy and crude original construction.
