# Model adapters

Create a model-neutral motion brief first. Apply a named provider only after storyboard approval, when the user explicitly requests prompt-only, or when the user supplies an already approved board.

## Dreamina / Seedance name-safe delivery

For a final video prompt intended for Seedance through Dreamina, omit the character name, the series title, and rights-holder names. Refer to the subject as `the approved reference character`, `the figure`, or by pronouns and shot-specific action.

The approved image or storyboard remains the immediate visual authority. Name scrubbing changes only provider-facing wording; it must not remove the identity mapping, neutral-expression default, full-body head-to-body scale, anatomy, leg topology, shot order, geography, or continuity locks.

If Dreamina restricts an image upload, respect the platform response. The user may optionally make a minor color correction in PS Express or a similar editor and export a fresh copy as a file-compatibility retry. A new export can change encoding or metadata, but this is not guaranteed and must not be represented as a moderation bypass. If the restriction persists, use another video-model platform whose policies permit the project.

Preserve, in order:

1. canonical identity authority and supplemental leg-topology authority
2. duration, aspect ratio, and ordered shot progression
3. camera and character action
4. continuity, scene geography, and end-state handoff
5. original-PS2 environment/render limits without modernizing Xavier
6. dialogue, caption, and audio behavior
7. decisive negatives
8. atmosphere and decorative detail

Never remove the anatomical-left snake arm, right-eye cyan/left-eye brown mapping, single backward-hinging knee per leg, shot order, geography, rendering target, or an explicit no-music constraint during compression.

When legs are visible, preserve one thigh, one true knee, one lower leg, one ankle, and one normal flat sneaker per leg. Do not compress this into vague terms such as `bird-like legs`; retain the explicit topology and rejection of standard forward human knees, animal hocks, and extra segments.

Do not invent provider features, field names, duration limits, image counts, or character limits. Use current verified documentation or a limit the user provides. If asked for an exact character limit, report the final count.

For image-to-video, state which approved image or storyboard is the immediate visual authority and keep both bundled assets available for anatomy repair. Prevent re-costuming, re-lighting, body mutation, identity interpolation, oversized-head drift, surprise-expression drift, knee-direction changes, camera-axis jumps, and new unrequested text/logos.
