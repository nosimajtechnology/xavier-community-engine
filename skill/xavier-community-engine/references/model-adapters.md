# Model adapters

Create a model-neutral motion brief first. Apply a named provider only after storyboard approval, when the user explicitly requests prompt-only, or when the user supplies an already approved board.

## fal.ai MiniMax H3 Max

For H3 Max, I2V, T2V, R2V, Classic Control, Direct Explore, or Character Lock,
read [fal-h3-max.md](model-adapters/fal-h3-max.md). That adapter controls route
selection, reference order, seed optimization, prompt structure, and verified
fal.ai fields. It may translate packaging but cannot override Xavier canon, leg
topology, approved continuity, or the selected style adapter.

## Dreamina / Seedance name-safe delivery

For a final video prompt intended for Seedance through Dreamina, omit the
character name, series title, and rights-holder names. Refer to the subject as
`the approved reference character`, `the figure`, or by pronouns and
shot-specific action.

The approved image or storyboard remains the immediate visual authority. Name
scrubbing changes only provider-facing wording; it must not remove identity,
neutral expression, full-body head-to-body scale, anatomy, leg topology, shot
order, geography, style, or continuity locks.

If Dreamina restricts an image upload, respect the platform response. A lightly
corrected fresh export may be suggested only as a file-compatibility retry,
with no guarantee. Never present metadata or re-encoding changes as a moderation
bypass. If the restriction persists, use another platform whose policies permit
the project.

## Image package

Include the canonical Xavier reference for identity, the leg authority whenever
legs may be visible, the selected adapter-specific sheet when active, the latest
approved project image when available, and only the style or gameplay references
whose narrow roles apply. Exception: for Late-Z H3 Max R2V, upload only the
bundled Late-Z Xavier sheet as `Image 1` by default. State wardrobe, props,
world, spatial layout, selected rendering contract, camera, composition, and
decisive negatives.

For that Late-Z R2V exception, the sheet is the complete identity, face,
asymmetric-anatomy, costume, proportion, palette, linework, cel-shading, and
broadcast-rendering authority. Add a reference only when requested, materially
required by the scene, or needed for a targeted repair. Keep the Late-Z sheet
first, give every addition one narrow role, and omit unused slots.

Preserve, in order:

1. canonical identity authority and supplemental leg-topology authority
2. duration, aspect ratio, and ordered shot progression
3. camera and character action
4. continuity, scene geography, and end-state handoff
5. selected style or original-PS2 environment/render limits without redesigning Xavier
6. dialogue, caption, and audio behavior
7. decisive negatives
8. atmosphere and decorative detail

Never remove the anatomical-left snake arm, right-eye cyan/left-eye brown mapping, neutral-expression default, full-body head-to-body scale, single backward-hinging knee per leg, shot order, geography, rendering target, or an explicit no-music constraint during compression.

When legs are visible, preserve one thigh, one true knee, one lower leg, one ankle, and one normal flat sneaker per leg. Do not compress this into vague terms such as `bird-like legs`; retain the explicit topology and rejection of standard forward human knees, animal hocks, and extra segments.

Do not invent provider features, field names, duration limits, image counts, or character limits. Use current verified documentation or a limit the user provides. If asked for an exact character limit, report the final count.

When a registered style adapter is active, preserve its display signifier,
rendering lock, temporal rhythm, motion profile, reference-role firewall,
expression preset, and exclusions. Keep any transformation pre-state,
change-only delta, and post-state explicit. Do not let provider syntax silently
replace adapter rules.

For image-to-video, state which approved image or storyboard is the immediate visual authority and keep both bundled canonical assets available for anatomy repair. Prevent re-costuming, re-lighting, body mutation, identity interpolation, knee-direction changes, camera-axis jumps, and new unrequested text/logos.

Avoid `smooth animation`, `fluid interpolation`, `glossy anime`, `cinematic
depth of field`, or `modern digital color` when a broadcast-cel adapter is
active. Do not invent provider fields or limits.
