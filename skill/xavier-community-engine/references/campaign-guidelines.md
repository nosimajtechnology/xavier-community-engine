# Optional $XAVIER / Shillz campaign route

This file applies only when the user requests a campaign, Shillz submission, token content, or equivalent. State when a rule comes from this optional route.

## Thesis

Xavier is the clip. The token is secondary.

## Pass gate

- Xavier is visible for most of the runtime through body, face, or unmistakable close-up.
- Hook within the first few seconds.
- Story is the A-plot and remains enjoyable without the token.
- Target 8–45 seconds; 60 seconds maximum.
- Smooth pacing, transitions, and continuous action.
- Meaningful transformation or original construction.
- Muted viewing communicates premise and progression.
- At most one cashtag or final end card, unless the active brief expressly requires otherwise.

## Fail gate

Reject charts/tickers/price talk as the A-plot, guaranteed returns, financial advice, fake contract addresses, raw episode dumps, unedited clips, stolen edits, foreign watermarks, copy-paste captions, static Xavier wallpaper, broken generated text, visible anatomy drift, disconnected slideshows, paid ads/bots/pods/views, engagement bait, or a hook made only from a token claim.

If the muted-view test fails or the idea only works as a shill, rewrite the story before packaging.
