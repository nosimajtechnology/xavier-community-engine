# Dialogue and wordplay

Write original lines with sincere pseudo-wisdom, confident false logic, and one semantic idea mutating through the sentence or scene. Useful mechanisms include malapropism, portmanteau, recursion, false etymology, bodily metaphor, and category confusion.

Prefer one strong chain to unrelated puns. Keep short-form dialogue speakable and subtitle-safe. Let supporting characters react to what happens instead of explaining the joke.

Do not copy recognizable show lines, reproduce scripts, name or imitate a specific performer, request voice cloning, or use generic philosophical filler that never changes the action.

Audio defaults to ambient game-world sound or SFX only. Do not use the original theme, show audio, or ripped dialogue. If voice is requested, describe vocal character, cadence, and dramatic function without naming a performer.
